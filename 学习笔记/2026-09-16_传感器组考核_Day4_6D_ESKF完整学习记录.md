# 2026-09-16 传感器组考核 Day4：6D Attitude ESKF 完整理论闭环

> 约定：Nominal Attitude 用 Quaternion 保存；Error State 用 3D Rotation Vector 描述；采用 **Right Multiplicative Error（右乘姿态误差）**。四元数顺序统一为 $q=[q_x,q_y,q_z,q_w]$。

---

# 一、前置基础与测量模型

前置只有两块：三维旋转（Rotation Matrix / Rotation Vector / Hat 算子 / Quaternion / SO(3)、so(3) / Exp、Log / Body 与 World Frame / 右乘局部旋转）与 Kalman Filter、EKF。核心前提是 Quaternion 与 Rotation Matrix 描述同一个姿态、只是表示形式不同，后续 3D Error State 正是把姿态误差从四元数空间中分离出来处理。

Gyroscope 测量模型：

$$
\omega_m=\omega_{\text{true}}+b_g+n_g
$$

其中 $\omega_m$ 是陀螺仪测量角速度，$\omega_{\text{true}}$ 是真实角速度，$b_g$ 是 Gyroscope Bias（陀螺零偏），$n_g$ 是 Gyroscope Measurement Noise（陀螺测量噪声）。Kalman Filter / EKF 基础符号：$P$ 是当前状态估计 uncertainty，$Q$ 是 Prediction 过程新增的 uncertainty，$R$ 是 Observation uncertainty，$f(\cdot)$ 是 State Transition Function，$F$ 是 $f$ 的 Jacobian，$h(\cdot)$ 是 Observation Function，$H$ 是 $h$ 的 Jacobian。关键分工：$f/h$ 负责真实的 nonlinear state / observation relationship；$F/H$ 只负责描述局部小误差如何传播。

---

# 二、普通 Additive EKF 不能直接处理 Quaternion

若直接把状态写成 $x=[q;b_g]$ 并做普通加法更新 $q^+=q^-+\delta q$，会出现四个问题：Quaternion 有单位约束 $\|q\|=1$，四个 scalar 并不是四个独立自由度；Rotation 只有 3 DOF（$q$ 有 4 个 scalar 但旋转自由度只有 3）；$q\equiv -q$，同一 Rotation 可由 $q$ 和 $-q$ 共同表示，因此四个分量之差并不等价于真实姿态误差；姿态差必须用 Relative Rotation 表示：

$$
q_{\text{rel}}=q_1^{-1}\otimes q_2
\qquad\text{或者}\qquad
R_{\text{rel}}=R_1^T R_2
$$

它 **不是** $q_2-q_1$。这正是本题选择 ESKF 的原因。

---

# 三、ESKF 核心：Nominal State 与 Error State 的分工

ESKF = Error-State Extended Kalman Filter，本质上仍然是 EKF，只是状态组织方式不同：Nominal State 保存完整非线性状态，Error State 只保存 Nominal 附近的小误差。

$$
\boxed{
\hat x=(\hat q,\hat b_g)
}
\qquad\qquad
\boxed{
\delta x=
\begin{bmatrix}
\delta\theta\\
\delta b_g
\end{bmatrix}
\in\mathbb R^6
}
$$

其中 $\hat q$ 是当前姿态估计，$\hat b_g$ 是当前 Gyro Bias estimate，存储上是 Quaternion 4 个 scalar 加 Bias 3 个 scalar 共 7 个；误差部分 $\delta\theta\in\mathbb R^3$ 是 Attitude Error Rotation Vector（姿态误差旋转向量），$\delta b_g\in\mathbb R^3$ 是 Gyro Bias Error。因此协方差为 6×6，描述的是 Error State 的 covariance，**不是** Quaternion 四个分量或 Rotation Matrix 9 个元素的 covariance：

$$
\boxed{
P\in\mathbb R^{6\times6}
}
\qquad
P=
\begin{bmatrix}
P_{\theta\theta}&P_{\theta b}\\
P_{b\theta}&P_{bb}
\end{bmatrix}
$$

$P_{\theta\theta}$ 是姿态误差 covariance，$P_{bb}$ 是 Bias Error covariance，$P_{\theta b},P_{b\theta}$ 是两者的 cross covariance。

---

# 四、右乘姿态误差约定与姿态误差动力学

本次统一采用 Right Multiplicative Error，$\delta R$ / $\delta q$ 是相对于当前 Nominal Body-local Frame 定义的小旋转误差，因此 $\delta\theta$ 也在当前 Body-local Frame 中表达：

$$
\boxed{
R_{\text{true}}=\hat R\,\delta R
}
\qquad\Longleftrightarrow\qquad
\boxed{
q_{\text{true}}=\hat q\otimes\delta q
}
\qquad\Longrightarrow\qquad
\delta q
\approx
\begin{bmatrix}
\frac12\delta\theta\\
1
\end{bmatrix}
$$

最后一步是小角度近似。这一 convention 一旦确定，后面的 Error Dynamics、$F_c$、$G_c$、residual、Injection、Reset 都必须保持一致。完整姿态误差动力学（Day4 最关键的公式之一）：

$$
\boxed{
\dot{\delta\theta}
=
-[\hat\omega]_\times\delta\theta
-\delta b_g
-n_g
}
\qquad\qquad
\boxed{
\dot{\delta b_g}=n_{bg}
}
$$

三项的物理含义要分清：

- $-[\hat\omega]_\times\delta\theta$：已存在的姿态误差在当前 Body-local Frame 中表达，而这个局部坐标系随 Nominal Attitude 旋转，因此已有误差的三个坐标分量也会变化。它是已有误差在旋转局部坐标中的 **coordinate transport（坐标输运）**，**不是新的误差来源**。例如误差原本在 Body $x$ 方向 $\delta\theta=[1^\circ,0,0]^T$，当 Body Frame 绕 $z$ 轴转动后，同一个空间小误差在新 Body Frame 中可能变成 $[0,-1^\circ,0]^T$，所以该项必须存在。
- $-\delta b_g$：Bias estimate 错误会使 $\hat\omega$ 偏离真实角速度，于是 $\delta b_g\rightarrow\text{Angular Velocity Error}\rightarrow\text{Attitude Error}$，并随时间积分累积。
- $-n_g$：Gyroscope Measurement Noise 直接污染姿态传播，因此进入姿态误差变化率。

---

# 五、$F_c$、$G_c$ 与连续噪声模型

$F_c$ 是误差动力学对 Error State 的 Jacobian（描述 $\delta x\rightarrow\dot{\delta x}$），$G_c$ 是对噪声的 Jacobian（描述 $w=[n_g;n_{bg}]\rightarrow\dot{\delta x}$）：

$$
\boxed{
F_c=
\begin{bmatrix}
-[\hat\omega]_\times&-I\\
0&0
\end{bmatrix}
}
\qquad\qquad
\boxed{
G_c=
\begin{bmatrix}
-I&0\\
0&I
\end{bmatrix}
}
$$

$F_c$ 的四个块：左上 $-[\hat\omega]_\times$ 是姿态误差因旋转坐标系而变化；右上 $-I$ 是 Bias Error 驱动 Attitude Error；左下 $0$ 是姿态误差不直接决定 Bias Random Walk；右下 $0$ 是当前 Bias Error 没有确定性的自演化项。$G_c$ 的对角结构来自 $-n_g$ 进入 $\dot{\delta\theta}$、$+n_{bg}$ 进入 $\dot{\delta b_g}$。拼起来就是误差状态方程：

$$
\boxed{
\dot{\delta x}=F_c\delta x+G_cw
}
$$

暂时认为三个轴噪声强度相同且互相独立，连续 Process Noise Covariance 为：

$$
\boxed{
Q_c=
\begin{bmatrix}
\sigma_g^2I&0\\
0&\sigma_{bg}^2I
\end{bmatrix}
}
$$

$\sigma_g^2$ 是 Gyro Measurement Noise 强度，$\sigma_{bg}^2$ 是 Bias Random Walk Driving Noise 强度。要点：$Q_c$ 表示**连续时间噪声统计强度**，不是一帧直接加到 $P$ 里的矩阵。

---

# 六、Gyro Noise 与 Bias Random Walk 的区别

真实 Bias 建模为随机游走，其误差满足 $\dot{\delta b_g}=n_{bg}$，几项定义放在一起对照：

$$
\boxed{
\dot b_g=n_{bg}
}
\qquad\qquad
\boxed{
\delta b_g=b_g-\hat b_g
}
\qquad\Longrightarrow\qquad
\boxed{
\dot{\delta b_g}=n_{bg}
}
$$

最后一步用到了 $\dot{\hat b}_g=0$。重要纠正：$n_g$ 是 Gyro Measurement Noise，直接污染当前角速度测量；$n_{bg}$ 驱动 Bias Random Walk。真正缓慢漂移的是 $b_g$ 本身，**不能把 $n_{bg}$ 简单称为“慢噪声”**。

---

# 七、连续模型离散化与 Covariance Prediction

$F_c$ 描述 $\delta x\rightarrow\dot{\delta x}$，而程序逐帧运行需要 $\delta x_{k-1}\rightarrow\delta x_k$，因此定义 State Transition Matrix $\Phi$。一阶 Taylor Approximation：

$$
\boxed{
\Phi\approx I+F_c\Delta t
}
\qquad\Longrightarrow\qquad
\boxed{
\Phi
\approx
\begin{bmatrix}
I-[\hat\omega]_\times\Delta t&-I\Delta t\\
0&I
\end{bmatrix}
}
$$

（此前曾用 $F_k$ 表示同一个离散状态转移概念，后续统一采用 $\Phi$，避免与 $F_c$ 混淆。）连续噪声到离散噪声的转换记为 $Q_c\xrightarrow{G_c,\Delta t,\text{离散化}}Q_d$，$Q_d$ 表示一帧内真正累计形成的 Process Noise Covariance；完整积分形式只要求知道其存在，不要求独立推导。当前掌握的一阶近似，以及最终的 Covariance Prediction：

$$
\boxed{
Q_d
\approx
G_cQ_cG_c^T\Delta t
}
\qquad\qquad
\boxed{
P_k^-
=
\Phi P_{k-1}^+\Phi^T+Q_d
}
$$

后者的含义是 $P^-=$ 旧不确定性的传播 $+$ 这一帧新增的不确定性。

---

# 八、Prediction 的两条主线

Prediction 同时完成两件事，一条预测状态本身，一条预测不确定性。第一条线是名义状态：$\omega_m\rightarrow\hat\omega\rightarrow\Delta\theta\rightarrow\Delta q\rightarrow\hat q^-$，同时 $\hat b_g^-\leftarrow\hat b_g^+$，回答“我认为当前状态在哪里？”。另一条线是误差协方差：

$$
\boxed{
\text{Error Dynamics}
\rightarrow
F_c,G_c,Q_c
\rightarrow
\Phi,Q_d
\rightarrow
P^-
}
$$

回答“我对这个预测有多不确定？”。两条线的分工必须分清，$P^-$ 只属于第二条线。

---

# 九、Nominal Prediction：Bias 补偿与右乘姿态传播

Gyroscope 测量 $\omega_m=\omega_{\text{true}}+b_g+n_g$，Nominal Prediction 使用当前 Bias estimate 做补偿并积分得到角增量，其中 $\hat\omega=\omega_m-\hat b_g$，$\Delta\theta=\hat\omega\Delta t$。再把角增量转成 Quaternion increment（$\Delta\theta\rightarrow\Delta q$）并右乘更新，最后归一化：

$$
\boxed{
\hat q_k^-
=
\hat q_{k-1}^+
\otimes
\Delta q
}
\qquad
\hat q_k^-
\leftarrow
\frac{\hat q_k^-}{\|\hat q_k^-\|}
$$

Nominal Bias Prediction 采用 $\dot{\hat b}_g=0$，即 $\hat b_{g,k}^-=\hat b_{g,k-1}^+$。注意：这**不代表真实 $b_g$ 不变**，而是 Nominal Prediction 中 Bias 的均值没有确定性变化项。

---

# 十、FAST-LIO Observation：从 Quaternion 得到 Residual

Prediction 得到 $\hat q_k^-$，FAST-LIO 提供 $q_{obs,k}$。因为 $q\equiv -q$，若 $\hat q_k^-\cdot q_{obs,k}<0$ 则先取 $q_{obs,k}\leftarrow -q_{obs,k}$；这只是统一 Quaternion 表示（双覆盖处理），**不改变实际姿态**。根据右乘误差定义 $q_{obs}\approx\hat q^-\otimes\delta q_{obs}$，得到 Relative Quaternion：

$$
\boxed{
\delta q_{obs}
=
(\hat q^-)^{-1}\otimes q_{obs}
}
$$

它描述“从当前 Prediction 到 FAST-LIO Observation 还差多少旋转”。再由四元数的旋转向量形式 $\delta q=[n\sin(\theta/2);\cos(\theta/2)]$ 反解 $\theta,n$，得到 $\delta\theta_{obs}=\theta n$。也可等价地走 $\delta q_{obs}\leftrightarrow\delta R_{obs}$，然后 $\delta\theta_{obs}=\mathrm{Log}(\delta R_{obs})^\vee$；当前不需要掌握 Quaternion ↔ Rotation Matrix 的详细运算，只需知道它们描述同一个 Relative Rotation、可以相互转换。最终 residual 取：

$$
\boxed{
r_\theta=\delta\theta_{obs}
}
$$

---

# 十一、Observation Model：$h(\cdot)$ 与 $H$ 的区别

Observation Model 为 $r_\theta=h(\delta x)+v$。当前 $h(\delta x)=\delta\theta$，因此

$$
\boxed{
H=
\frac{\partial h}{\partial\delta x}
=
[I\quad0]
}
$$

易错点：$h(\cdot)$ 是函数，$H$ 是 Jacobian，二者不是同一个数学对象；当前只是因为 $h(\delta x)=\delta\theta$ 很简单，看起来像 $h(\delta x)=H\delta x$。另外 FAST-LIO 直接观测 $\delta\theta$，**不直接观测** $\delta b_g$。

---

# 十二、观测噪声 $R$、Innovation Covariance $S$ 与 Kalman Gain $K$

$R$ 定义为观测噪声的 covariance，即 $R=\operatorname{Cov}(v)$。题目提供 FAST-LIO pose covariance，并要求使用姿态对角项 $cov_{33},cov_{44},cov_{55}$：

$$
\boxed{
R=
\operatorname{diag}
(cov_{33},cov_{44},cov_{55})
}
$$

它表示这次姿态 Observation 有多可信：$R$ 大 $\Rightarrow$ Observation 不可靠，$R$ 小 $\Rightarrow$ Observation 更可靠。注意：严格几何上 RPY covariance 与 Rotation Vector covariance 并非任意姿态下完全等价，当前按题目要求，仅在小误差局部线性条件下使用。

Innovation Covariance 的含义是“当前 residual 本身有多不确定”，其中 $HP^-H^T$ 把 6D Error State covariance 投影到 3D Observation Space，因为 $H=[I\quad0]$ 所以只剩下姿态块：

$$
\boxed{
S=HP^-H^T+R
}
\qquad\Longrightarrow\qquad
\boxed{
S=P_{\theta\theta}^-+R
}
$$

即 Residual uncertainty $=$ Prediction uncertainty in observation space $+$ Observation uncertainty。Kalman Gain 及其分块为：

$$
\boxed{
K=P^-H^TS^{-1}
}
\qquad\qquad
\boxed{
K=
\begin{bmatrix}
K_\theta\\
K_b
\end{bmatrix}
}
$$

维度是 $K\in\mathbb R^{6\times3}$，其中 $K_\theta=P_{\theta\theta}^-S^{-1}$ 负责姿态 correction，而 $K_b=P_{b\theta}^-S^{-1}$ 负责通过姿态 residual 间接修正 Bias。这正是“只观测 $\delta\theta$ 却能修正 $\delta b_g$”的机制：因为 $\delta b_g\rightarrow\dot{\delta\theta}$，两者在 Prediction 中建立了相关性，因此可以借助对 $\delta\theta$ 的 observation 和修正来间接修正 $\delta b_g$。

---

# 十三、Error State Correction 与 Error Injection

Error State Correction 由 Kalman Gain 乘 residual 得到：

$$
\boxed{
\delta\hat x
=
Kr_\theta
}
\qquad\Longrightarrow\qquad
\boxed{
\delta\hat x=
\begin{bmatrix}
\delta\hat\theta\\
\delta\hat b_g
\end{bmatrix}
}
$$

注意区分：$r_\theta$ 表示 Prediction 和 Observation **差多少**；而 $\delta\hat\theta$ 表示 Kalman 综合 $P^-$ 与 $R$ 后**最终决定真正修多少**。两者通常不相等。

姿态 Injection 先做 $\delta\hat\theta\rightarrow\delta\hat q$，完整形式为 $\delta\hat q=[n\sin(\theta/2);\cos(\theta/2)]$，小角度近似为 $\delta\hat q\approx[\frac12\delta\hat\theta;1]$。按照右乘 convention：

$$
\boxed{
\hat q^+
=
\hat q^-\otimes\delta\hat q
}
\qquad\Longrightarrow\qquad
\boxed{
\hat b_g^+
=
\hat b_g^-+\delta\hat b_g
}
$$

姿态随后 Normalize，Bias 那边由 $\delta b_g=b_g-\hat b_g$ 得到加法注入。Injection 的本质：把 Kalman 估计出的 correction 真正吸收到 Nominal State 中。

---

# 十四、Observation 后的 covariance 更新

Observation 不仅修正状态，也会改变我们对 Error State uncertainty 的判断。简洁形式 $P_{\text{upd}}=(I-KH)P^-$，工程上更推荐 Joseph Form，因为它数值上更容易保持 symmetry 与 positive semi-definiteness：

$$
\boxed{
P_{\text{upd}}
=
(I-KH)P^-(I-KH)^T
+
KRK^T
}
$$

此时 $P_{\text{upd}}$ 已经融合 FAST-LIO 信息，但仍然是相对于 **Injection 前旧 Error State reference** 表达的 covariance。

---

# 十五、Error Reset：Reset 不是把 $P$ 清零

这是 Day4 后半段最容易混淆的部分。Injection 前 $R_{\text{true}}=\hat R^-\delta R_{\text{old}}$，Injection 时 $\hat R^+=\hat R^-\mathrm{Exp}(\delta\hat\theta)$，Injection 后按新 reference 重新定义 $R_{\text{true}}=\hat R^+\delta R_{\text{new}}$，于是新旧误差坐标的关系，以及 Error State 估计均值回零为：

$$
\boxed{
\delta R_{\text{new}}
=
\mathrm{Exp}(-\delta\hat\theta)
\delta R_{\text{old}}
}
\qquad\qquad
\boxed{
\delta\hat x\leftarrow0
}
$$

已经估计出的 correction 被吸收到 Nominal State 后，Error State 的估计均值重新以新的 Nominal State 为中心。必须澄清：这**不代表** $\text{True Error}=0$，**也不代表** $P=0$。Reset 不是把真实误差清零，也不是把不确定度清零，只是把误差参考系搬到新的 Nominal State 上。

---

# 十六、为什么 Reset 后 $P$ 还要做 Jacobian 变换

Observation Update 后 $P_{\text{upd}}$ 描述的是旧 Error State $\delta x_{\text{old}}$ 的不确定性；但 Injection 后我们使用 $\delta x_{\text{new}}$，因此发生了变量重新定义 $\delta x_{\text{old}}\rightarrow\delta x_{\text{new}}$，Covariance 必须跟着做 Jacobian 变换：

$$
\boxed{
P^+
=
G_{\text{reset}}
P_{\text{upd}}
G_{\text{reset}}^T
}
\qquad\qquad
\boxed{
G_{\text{reset}}
\approx
\begin{bmatrix}
I-\frac12[\delta\hat\theta]_\times&0\\
0&I
\end{bmatrix}
}
$$

这个 $\frac12$ 来自右乘误差 convention 下新旧误差坐标的一阶关系（小角度 $\delta q\approx[1/2\,\delta\theta;1]$）；当前不要求独立推导该 $\frac12$ 项，只需理解机制。

---

# 十七、为什么一帧里 $P$ 会“变三次”

完整链为 Prediction、Observation、Reset 三次变化：

$$
\boxed{
P_{k-1}^+
\xrightarrow{\text{Prediction}}
P_k^-
\xrightarrow{\text{Observation}}
P_{k,\text{upd}}
\xrightarrow{\text{Reset}}
P_k^+
}
$$

三次变化的性质完全不同：**第一次 Prediction** $P_{k-1}^+\rightarrow P_k^-$，uncertainty 随时间传播，并加入新的 Process Noise；**第二次 Observation Update** $P_k^-\rightarrow P_{k,\text{upd}}$，融合 FAST-LIO 新信息后对 uncertainty 的真正 Kalman 更新；**第三次 Reset** $P_{k,\text{upd}}\rightarrow P_k^+$，把同一份后验 uncertainty 从旧 Error 坐标重新表达进新的 Error 坐标。第三步**不是**再次融合 Observation，**不是**“第三次相信 FAST-LIO”，而是 **re-expression（重新表达）**。

---

# 十八、$P$ 到底描述谁

最终确认 $P=\operatorname{Cov}(\delta x)$，姿态部分为 $P_{\theta\theta}=\operatorname{Cov}(\delta\theta)$，它**不是** Nominal Rotation $R$ 的 covariance。更准确地说：$P$ 描述 Error State 的 uncertainty，其中姿态部分描述相对姿态误差 $\delta R$ 对应的小 Rotation Vector $\delta\theta$ 的 covariance。这也是为什么 $P\in\mathbb R^{6\times6}$，而不是对 Rotation Matrix 的 9 个元素做 $9\times9$ covariance。

---

# 十九、FAST-LIO 为什么能抑制 Yaw Drift

Gravity Observation 可以帮助 Roll / Pitch，因为 Roll / Pitch 会改变重力在 Body Frame 中的方向。但 Yaw 是绕重力轴旋转，因此单靠重力无法长期约束 Yaw：

$$
\boxed{
Yaw\ change
\not\Rightarrow
Gravity\ direction\ change
}
$$

而 Gyro 的 $z$-axis Bias 经过积分会造成 $b_{g,z}\ error\rightarrow Yaw\ Drift$。FAST-LIO 提供完整 Attitude Quaternion，因此能形成 **Yaw 方向的姿态 residual**，从而给出 Yaw 约束并抑制漂移：

$$
\boxed{
FAST\text{-}LIO
\rightarrow
Yaw\ Constraint
\rightarrow
抑制\ Yaw\ Drift
}
$$

并进一步可通过 $P_{b\theta}$ 间接修正 $b_{g,z}$。

---

# 二十、EKF 与 ESKF 的最终关系

ESKF 不是和 EKF 平行的一套完全独立算法，更准确地说，**ESKF 是 EKF 的一种状态组织方式**。Nominal State $\hat x=(\hat q,\hat b_g)$ 负责保存与传播完整 nonlinear state；Error State $\delta x=[\delta\theta;\delta b_g]$ 负责在 Nominal 附近的小误差线性空间中运行 EKF。因此以下五步共同构成完整 ESKF：

$$
\boxed{
\text{Nominal Prediction}
+
\text{Error-State Linearization}
+
\text{Kalman Update}
+
\text{Injection}
+
\text{Reset}
}
$$

它特别适合姿态问题的原因：Quaternion 很适合表示完整姿态，而小 Rotation Vector 很适合在局部欧氏空间中做 EKF。

# 二十二、必须保留的认知修正与易错点

1. **姿态误差动力学不能用简化版**。曾为了单独解释 Bias / Noise 的作用使用过 $\dot{\delta\theta}\approx-\delta b_g-n_g$ 以及对应的 $F_c=\begin{bmatrix}0&-I\\0&0\end{bmatrix}$，这会遗漏当前右乘 3D ESKF 中必须存在的 $-[\hat\omega]_\times\delta\theta$，**不得作为当前题目的正式模型使用**。正式模型为：

$$
\boxed{
\dot{\delta\theta}
=
-[\hat\omega]_\times\delta\theta
-\delta b_g
-n_g
}
\qquad\qquad
\boxed{
F_c=
\begin{bmatrix}
-[\hat\omega]_\times&-I\\
0&0
\end{bmatrix}
}
$$

由此形成的原则：对核心模型和会影响后续代码实现的公式，必须先给出完整正确版本；如果为了局部分析暂时忽略某些项，必须明确标注“局部简化”并说明忽略条件，不能让简化版成为主线认知。

2. **$n_{bg}$ 不是“慢噪声”**。它是驱动 Bias Random Walk 的噪声，真正表现为缓慢变化的是 $b_g$，而不是把 $n_{bg}$ 本身理解为一个慢变化量。

3. **$-[\hat\omega]_\times\delta\theta$ 为什么存在**：因为采用 Right Multiplicative Error，$\delta\theta$ 在随 Nominal Attitude 一起旋转的 Body-local Frame 中表达；即使同一个空间误差没有变大，它在旋转局部坐标轴中的三个分量也会变化。它描述的是已有姿态误差的 coordinate transport，不是新的误差来源。

4. **不要把 $h(\cdot)$ 与 $H$ 混为一谈**。$h(\cdot)$ 是 Observation Function，$H=\frac{\partial h}{\partial x}$ 是 Observation Jacobian；当前因为 $h(\delta x)=\delta\theta$ 恰好是线性的才有 $h(\delta x)=H\delta x$，但二者不是同一个数学对象。

5. **只观测 $\delta\theta$ 却能修正 $\delta b_g$**：因为 $\delta b_g\rightarrow\dot{\delta\theta}\rightarrow\delta\theta$，使两者在 Prediction 中建立 cross covariance $P_{b\theta}$，因此 $K_b=P_{b\theta}S^{-1}$ 可以让姿态 residual 间接产生 Bias correction。

6. **$P$ 一帧“更新三次”的性质区分**：$P_{k-1}^+\rightarrow P_k^-$ 是 Prediction propagation；$P_k^-\rightarrow P_{k,\text{upd}}$ 是 FAST-LIO Observation 带来的真正 Kalman covariance update；$P_{k,\text{upd}}\rightarrow P_k^+$ 是 Injection 后新的 Error coordinate 下的 covariance re-expression，第三步不是再次融合 Observation。

7. **$P$ 描述 $\delta R$ 而不是 $R$**：$P=\operatorname{Cov}(\delta x)$，姿态部分 $P_{\theta\theta}=\operatorname{Cov}(\delta\theta)$，所以 $P$ 描述姿态 **Error State** 的 uncertainty，而不是 Nominal Rotation Matrix $R$ 本身的 covariance。

8. **Reset 不是把 $P$ 清零**：Reset 只把误差均值重新置零并把 covariance 换到新 Error 坐标，真实误差与不确定度都不为零。

# 二十四、Day4 完整总链

完整主线一图流：从上一帧 $(\hat q^+,\hat b_g^+,P^+)$ 出发，经 IMU Nominal Prediction 得到 $\hat q^-,\hat b_g^-$，同时进行误差状态预测 $F_c,G_c,Q_c\rightarrow\Phi,Q_d\rightarrow P^-$；再进入观测与更新（$\text{FAST-LIO Observation}\rightarrow q_{obs},\hat q^-\rightarrow\delta q_{obs}\rightarrow r_\theta$）：

$$
\boxed{
H,R
}
\rightarrow
\boxed{
S=HP^-H^T+R
}
\rightarrow
\boxed{
K=P^-H^TS^{-1}
}
\rightarrow
\boxed{
\delta\hat x=Kr_\theta
}
$$

随后注入与复位，最后回到下一帧：

$$
\begin{aligned}
&\boxed{
\text{Injection}
}
\qquad
\hat q^+=\hat q^-\otimes\delta\hat q
\qquad
\hat b_g^+=\hat b_g^-+\delta\hat b_g\\[4pt]
&\boxed{
\text{Observation covariance update}
}
\rightarrow
\boxed{
P_{\text{upd}}
}
\rightarrow
\boxed{
\text{Reset}
}
\qquad

=
G_{\text{reset}}
P_{\text{upd}}

\end{aligned}
$$

$$
\boxed{
\text{ESKF 用 Quaternion 保存和传播完整姿态，
