# 2. Quaternion 分量顺序约定

本次考核统一采用虚部在前、实部在后的顺序，即 $q=[q_x,q_y,q_z,q_w]$ ，等价地写作 $q=[\mathbf v,w]$ 。其中 $\displaystyle \mathbf v= [q_x,\ q_y,\ q_z]^T$
这三个分量是虚部， $w=q_w$ 是实部。教材中经常写 $q=[s,\mathbf v]^T$ ，即实部在前，与本次约定正好相反；两种写法描述的是同一个对象，只是排列位置不同，因此读公式前必须先确认作者用的是哪一种顺序，否则后面的乘法与旋转结果都会整体错位。

> **易错点：教材公式、Eigen、ROS、FAST-LIO、自己写的代码，Quaternion 分量顺序可能不同。** 本次考核统一按 $[q_x,q_y,q_z,q_w]$ 。

# 3. Frame、向量与向量坐标

**Frame = Reference Frame / Coordinate Frame，参考坐标系**，回答“我用哪一套坐标轴描述这个空间量”。机器人中常见 World Frame $W$ 、Body Frame $B$ 、IMU Frame；同一个量在不同 Frame 下的数值可以完全不同，因此任何坐标都必须和它的 Frame 一起说才有意义。

核心边界：**向量本身 ≠ 向量坐标**。同一个物理向量 $\mathbf p$ 在不同 Frame 下写成 $\mathbf p_W$ 与 $\mathbf p_B$ ，即使 $\displaystyle \mathbf p_W\neq\mathbf p_B$
也不意味着物理向量 $\mathbf p$ 本身改变：机器人旋转时，空间中固定向量本身不变，变化的是它在 Body Frame 下的坐标表示。换句话说， $\mathbf p_W$ 与 $\mathbf p_B$ 是同一个空间点在两套坐标轴下的两组数字，上标只标记“在哪套 Frame 下读取”，不标记“是哪个向量”。

---

# 4. Orientation / Attitude / Pose 的区别

Orientation = 朝向，指刚体相对参考 Frame 的旋转关系，不包含位置。Attitude = 姿态，在 IMU / 航空航天 / 惯性导航中通常主要指旋转状态，因此 $Attitude\approx Orientation$ 。Pose = 位姿则包含平移与旋转两部分： $\displaystyle  Pose=Position+Orientation $
三维刚体完整 Pose 有 3 个平移自由度 + 3 个旋转自由度，合计 $6\mathrm{\ DOF}$ 。边界示例：机器人向前移动 2 m 而朝向不变 → Orientation / Attitude 不变，Pose 改变。

---

# 5. 姿态表示的整体地图

同一个三维 Rotation 可以有多种数学表示：Rotation Matrix、Rotation Vector / Axis-Angle、Euler Angle、Quaternion。

```text
Rotation
├─ Rotation Matrix
├─ Rotation Vector / Axis-Angle
├─ Euler Angle
└─ Quaternion
```

核心结论是 $\displaystyle  \text{它们不是四种不同的旋转，而是同一个 Rotation 的不同参数化方式} $
也就是说，Rotation 本身是几何对象，Rotation Matrix / Rotation Vector / Euler Angle / Quaternion 只是它的四套“坐标”，四者之间可以互相换算而不改变被描述的那个旋转。选哪一种，取决于当前要做什么运算：求复合、求误差、给人看，各自有不同取舍。

# 6. Rotation Matrix 及其约束

Rotation Matrix 记为 $R\in\mathbb R^{3\times3}$ ，它的作用是把一个三维坐标线性映射成另一个三维坐标，并且保持长度与夹角不变。合法旋转矩阵必须满足正交性 $\displaystyle  R^TR=I $
与右手性约束 $\displaystyle  \det(R)=1 $
正交性保证旋转不改变长度，行列式为 $+1$ 则排除镜像反射，把范围限制在真正的旋转上。所有合法三维旋转矩阵组成 $SO(3)$ ，即 **SO(3) = Special Orthogonal Group，三维特殊正交群**；Day 1 只需知道它是所有合法三维 Rotation Matrix 的集合，李群、李代数留到 Day 2。

## 6.1 为什么 9 个元素只有 3 个自由度

普通 $3\times3$ Matrix 有 9 个数，但 Rotation Matrix 的列向量长度必须为 1、不同列必须互相正交、且 $\det(R)=1$ ，这些约束互相并不独立：正交条件 $R^TR=I$ 给出 6 条独立等式，再加上 $\det(R)=1$ ，独立的约束一共 6 条，因此 9 个参数中只剩 $3\text{ 个旋转自由度}$ 。因此 Rotation Matrix 是一种冗余表示。

## 6.2 易错点：正交矩阵 ≠ 正定矩阵

描述 Rotation Matrix 约束时，正确说法是 $\text{正交矩阵}$ ，而不是 $\text{正定矩阵}$ 。二者的判据完全不同：正交性由 $R^TR=I$ 给出，而正定性要求 $\displaystyle x^TAx>0,\qquad x\neq0$
对任意非零向量成立，这与旋转矩阵无关。

## 6.3 坐标变换方向

沿 $B\rightarrow W$ 方向的变换为 $\displaystyle \mathbf p_W=R_{WB}\mathbf p_B$
其中 $R_{WB}:B\rightarrow W$ 表示把 Body Frame 下的坐标转换成 World Frame 下的坐标。反方向为 $R_{BW}=R_{WB}^{-1}$ ；对 Rotation Matrix 因为 $R^{-1}=R^T$ ，于是 $\displaystyle  R_{BW}=R_{WB}^T $
相应地 $\mathbf p_B=R_{BW}\mathbf p_W$ 。

# 7. Rotation Vector / Axis-Angle

**Axis-Angle = 轴角表示**：任意三维 Rotation 可描述成绕单位轴 $\mathbf n$ （满足 $\|\mathbf n\|=1$ ）转动角度 $\theta$ 。把二者相乘得到 $\boldsymbol\phi=\theta\mathbf n$ ，其中 $\boldsymbol\phi\in\mathbb R^3$ 称为 **Rotation Vector，旋转向量**。核心直觉是：**方向等于旋转轴，长度等于旋转角**，即 $\displaystyle \theta=\|\boldsymbol\phi\|, \qquad \mathbf n= \frac{\boldsymbol\phi}{\|\boldsymbol\phi\|}$
## 7.1 示例与误区

例如 $\boldsymbol\phi=[\pi/2,0,0]^T$ 表示绕 $X$ 轴旋转 $90^\circ$ 。

而 $\boldsymbol\phi=[1,1,0]^T$ **不能**理解成“先绕 X 轴转 1 rad，再绕 Y 轴转 1 rad”。正确读法是先算总旋转角 $\displaystyle \theta= \sqrt{1^2+1^2} = \sqrt2$
再算旋转轴 $\displaystyle \mathbf n= \frac1{\sqrt2} [1,\ 1,\ 0]^T$
所以它表示 $\text{绕 }[1,1,0]^T\text{ 对应的单位方向旋转 }\sqrt2\mathrm{\ rad}$ 。因为 $n$ 是单位向量，所以 $\phi=\theta n$ 成立，即 $\|\phi\|=\theta$ 。

## 7.2 与其他表示的关系及与 ESKF 的联系

Rotation Vector 与 Rotation Matrix 之间可以互相转换（ $\mathrm{Rotation\ Vector}\leftrightarrow\mathrm{Rotation\ Matrix}$ ），Rotation Vector → Rotation Matrix 通过 Rodrigues Formula 完成，Day 1 不要求推导。考核题明确规定姿态误差使用 $\delta\theta\in\mathbb R^3$ ，直觉上 $\delta\theta\text{ 可以看作一个“小旋转向量”}$ ；真正的 Error-State 结构留到 Day 4。

---

# 8. Euler Angle / Roll-Pitch-Yaw

**Euler Angle = 欧拉角**：通过三次有顺序的单轴旋转表示一个三维 Rotation。本文采用 ZYX 顺序，即 yaw-pitch-roll，写成 Rotation Matrix 为 $\displaystyle  R=R_z(\psi)R_y(\theta)R_x(\phi) $
其中 $\phi$ ：Roll， $\theta$ ：Pitch， $\psi$ ：Yaw。当前坐标约定 $X$ 前、 $Y$ 右、 $Z$ 上，因此 Roll 绕 $X$ 、Pitch 绕 $Y$ 、Yaw 绕 $Z$ ；机器人保持水平原地改变朝向时只有 $Yaw\text{ 变化}$ 。写成矩阵连乘的顺序必须与“先绕哪个轴”一致：式子从右往左依次作用，所以最右边是最先执行的那一次单轴旋转，这一点与后面 Quaternion 乘法里“先做的放右边”是同一条规则。

三维 Rotation 还不满足交换律： $\displaystyle  R_1R_2\neq R_2R_1 $
所以“先绕 X 再绕 Y”与“先绕 Y 再绕 X”一般得到不同姿态，最终结果与旋转顺序有关。这个知识后面直接用于 Quaternion multiplication。

---

# 9. Gimbal Lock

**Gimbal Lock = 万向锁**。对本文采用的 ZYX Euler Angle，当 $Pitch=\pm90^\circ$ 时会出现参数化奇异。本质：**不是机器人真的失去一个旋转自由度**，真实刚体仍有 $3\mathrm{\ rotational\ DOF}$ ，出问题的是 $Euler Angle \text{参数化}$ 。

在奇异位置，原本应当独立的两个旋转方向发生退化 —— 真实刚体没有少自由度，只是 ZYX Euler Angle 在该姿态下无法独立地区分全部旋转方向。因此在奇异位置附近，小的真实姿态变化可能对应很大的 Euler 数值变化，连续传播和滤波变得不稳定，结论是 $\displaystyle  Euler Angle \text{适合看，不适合长期作为内部姿态状态} $

# 10. Quaternion 基础与运算

**Quaternion = 四元数**，题目二采用 $q=[q_x,q_y,q_z,q_w]$ ，也写作 $q=[\mathbf v,w]$ ，其中 $\mathbf v$ 是三维虚部， $w$ 是实部。**重要边界：** $q_x,q_y,q_z,q_w$ **不是四个独立旋转角**，它们共同组成一个 Quaternion，整体表示一个 Rotation。

## 10.1 Quaternion 与 Axis-Angle

给定单位旋转轴 $\mathbf n$ 与旋转角 $\theta$ ，对应单位 Quaternion 为 $\displaystyle  q= \left[ \mathbf n\sin\frac{\theta}{2}, \cos\frac{\theta}{2} \right] $
写成分量形式即 $\displaystyle q= [n_x\sin(\theta/2),\ n_y\sin(\theta/2),\ n_z\sin(\theta/2),\ \cos(\theta/2)]^T$
示例：绕 X 轴旋转 $60^\circ$ 时 $\mathbf n=[1,0,0]^T$ 、 $\theta=60^\circ$ ，于是 $\displaystyle q= [\sin30^\circ,\ 0,\ 0,\ \cos30^\circ]^T = [1/2,\ 0,\ 0,\ \sqrt3/2]^T$
## 10.2 为什么出现 $\theta/2$

Quaternion 内部采用半角参数化 $q=[n\sin\frac{\theta}{2},\cos\frac{\theta}{2}]$ ，而真正旋转三维向量时使用 $\displaystyle p'=q\otimes p\otimes q^{-1}$
两次半角相乘最终在三维空间产生完整的 $\theta$ Rotation。当前认知状态是 $\text{知道公式、知道工程意义，但尚未做严格证明}$ 。

## 10.3 Unit Quaternion

表示 Rotation 的 Quaternion 必须满足归一化约束 $\|q\|=1$ ，等价地 $\displaystyle  q_x^2+q_y^2+q_z^2+q_w^2=1 $
这正是自由度计数的来源：四个分量 $q_x,q_y,q_z,q_w$ 减去一个约束，得到 $4-1=3$ 。

## 10.4 Quaternion Multiplication

$q_1\otimes q_2$ 表示两个 Rotation 的复合，与 Rotation Matrix 的 $R_1R_2$ 高度对应。在本文采用的主动旋转 convention 下，若先执行 $q_x$ 再执行 $q_y$ ，则 $\displaystyle  q_{\mathrm{total}} = q_y\otimes q_x $ 即**先进行的放在右边**。四元数乘法一般不满足交换律： $\displaystyle  q_1\otimes q_2\neq q_2\otimes q_1 $
这与三维 Rotation 本身的顺序性完全对应。

## 10.5 Conjugate / Inverse

若 $q=[\mathbf v,w]$ ，则共轭为 $q^*=[-\mathbf v,w]$
即只把虚部取反： $\displaystyle q^*= [-q_x,-q_y,-q_z,q_w]$
一般 Quaternion 的逆为 $q^{-1} = q^* / \|q\|^2$
推导方式是让 Quaternion 与其共轭相乘：虚部抵消、实部得到 $\|q\|^2$ ，即 $q\otimes q^*=\|q\|^2$ ；而 inverse 的定义要求 $q\otimes q^{-1}=1$ ，两者相除即可反解出逆的表达式： $q\otimes q^* / \|q\|^2 = (q\otimes q^*) / \|q\|^2 = 1$
由此可见当 $\|q\|=1$ （单位四元数）时才有 $q^{-1}=q^*$ 。

**物理意义**：若 $q$ 表示绕某轴 $+\theta$ ，则其逆 $q^{-1}$ 表示同一轴上的 $-\theta$ ，也就是把这个旋转原路退回去；例如 $Y\text{ 轴 }+30^\circ$ 的 inverse 表示 $Y\text{ 轴 }-30^\circ$ 。这正是旋转向量 $q p q^{-1}$ 中要用逆的原因：左乘做旋转、右乘把结果送回原坐标系。

# 11. $q$ 与 $-q$ ：Double Cover

$\displaystyle  q\equiv -q $ 即 $q$ 与 $-q$ 表示同一个三维 Rotation，这叫 **Double Cover = 双覆盖**。

## 11.1 关键区分： $q^{-1}\neq -q$

这是最重要的概念边界之一。 $q^{-1}=[-\mathbf v,w]$ 只有虚部变号，它表示 $\text{反向 Rotation}$ ，即 $+\theta\rightarrow-\theta$ ；而 $-q=[-\mathbf v,-w]$ 四个分量全部变号，它表示 $\text{同一个 Rotation 的另一个 Quaternion 表示}$ 。因此 $\displaystyle  q^{-1}\neq -q $
## 11.2 为什么 $-q$ 不是反向 Rotation

把 Quaternion 写成 $q(\theta)=[n\sin\frac{\theta}{2},\cos\frac{\theta}{2}]$ ，则 $\displaystyle q(\theta+2\pi) = -q(\theta)$
而真实三维 Rotation 满足 $R(\theta+2\pi)=R(\theta)$ ，所以 $q\text{ 和 }-q\text{ 最终对应同一个空间姿态}$ 。在“实际运动路径”层面可以说转 $90^\circ$ 与转 $450^\circ$ 是两种不同运动过程却到达同一姿态；但数学上更准确地说：** $q$ 和 $-q$ 不是两个不同 Rotation，而是同一个 Rotation 的两个 Quaternion 表示。**

# 12. Quaternion 旋转三维向量

三维向量 $\mathbf p=[p_x,p_y,p_z]^T$ 按照题目二 `[x,y,z,w]` convention 嵌入为 $\displaystyle  p=[p_x,p_y,p_z,0] $
这叫 **Pure Quaternion = 纯四元数 / 纯虚四元数**。旋转公式为 $\displaystyle  p' = q\otimes p\otimes q^{-1} $
结果仍是纯 Quaternion，取前三个分量就是旋转后的三维向量。它与 Rotation Matrix 的 $\mathbf p'=R\mathbf p$ 对应，Quaternion 形式写作 $p'=q p q^{-1}$ ，二者做的是同一个 Rotation。

自测示例：取 $\mathbf p=[1,0,0]^T$ ，则 Pure Quaternion 为 $p=(1,0,0,0)$ ；若 $q$ 表示绕 $Z$ 轴旋转 $90^\circ$ ，则 $X^+\rightarrow Y^+$ 。

# 13. Quaternion 与 Rotation Matrix 的类比与边界

| Rotation Matrix | Quaternion | 物理意义 |
|---|---|---|
| $R$ | $q$ | 表示 Rotation |
| $R_2R_1$ | $q_2\otimes q_1$ | Rotation 复合 |
| $R^{-1}=R^T$ | $q^{-1}=q^*$ （单位 q） | 反向 Rotation |
| $R p$ | $q p q^{-1}$ | 旋转向量 |
| $R^TR=I,\det R=1$ | $\|q\|=1$ | 合法 Rotation 约束 |
| 9 参数 / 3 DOF | 4 参数 / 3 DOF | 冗余表示 |

**必须保留的边界**：Quaternion **不是 Matrix**。更准确地说， $\displaystyle  \text{Quaternion 与 Rotation Matrix 是两种不同数学对象，但在表示和组合三维 Rotation 时功能高度对应} $
今日建立的核心关系是四个表示两两等价： $\displaystyle  \mathrm{Rotation\ Matrix} \leftrightarrow \mathrm{Rotation\ Vector} \leftrightarrow \mathrm{Quaternion} \leftrightarrow \mathrm{Euler\ Angle} $

# 14. Quaternion → Rotation Matrix → Roll/Pitch/Yaw

若 $q=[x,y,z,w]$ ，则对应的 Rotation Matrix 为 $\displaystyle R= [1-2(y^2+z^2),\ 2(xy-zw),\ 2(xz+yw);\ 2(xy+zw),\ 1-2(x^2+z^2),\ 2(yz-xw);\ 2(xz-yw),\ 2(yz+xw),\ 1-2(x^2+y^2)]$
这个公式可以理解成把 $q p q^{-1}$ 展开以后整理成 $R p$ ，因此 $\displaystyle  q\text{ 和 }R \text{执行的是同一个 Rotation} $
## 14.1 转 RPY 必须先规定 Euler Convention

在当前 ZYX 约定下 $R=R_z(Yaw)R_y(Pitch)R_x(Roll)$ ，从 Rotation Matrix 提取角度用 $\displaystyle Roll = \mathrm{atan2}(R_{32},R_{33}) \qquad Pitch = \arcsin(-R_{31}) \qquad Yaw = \mathrm{atan2}(R_{21},R_{11})$
把 Quaternion → Rotation Matrix 的公式代入即可得到 Quaternion → RPY。在当前 convention 下 $q=[x,y,z,w]$ ： $\displaystyle Roll = \mathrm{atan2}\left(2(wx+yz),\ 1-2(x^2+y^2)\right) \qquad Pitch = \arcsin\left(2(wy-zx)\right) \qquad Yaw = \mathrm{atan2}\left(2(wz+xy),\ 1-2(y^2+z^2)\right)$
## 14.2 为什么 Quaternion 转 RPY 还要规定顺序

这不是简单地“四个数字变成三个数字”，而是 $\displaystyle  Quaternion \rightarrow \text{同一个} Rotation \rightarrow \text{按指定} Euler convention \text{重新参数化} $
即 $\displaystyle  Quaternion \rightarrow Rotation Matrix \rightarrow \text{按某种} Euler Convention \text{分解} \rightarrow Roll/Pitch/Yaw $
因为在第二步 Rotation Matrix → Roll/Pitch/Yaw 时要规定旋转顺序，所以 ZYX、XYZ 等 convention 必须提前固定。

# 15. Quaternion 连续数据的符号问题

由于 $q\equiv -q$ ，连续姿态数据可能出现 $q_k$ 突然换成 $-q_k$ 的情况，即使真实姿态几乎没变。因此 $\displaystyle  \text{Quaternion 四个分量变化很大} \not\Rightarrow \text{真实姿态变化很大} $
处理办法是取相邻两帧的内积 $d=q_{k-1}^Tq_k$ ，当 $d<0$ 时执行 $\displaystyle  q_k\leftarrow -q_k $
即从 $q_k$ 与 $-q_k$ 两个等价表示中选择离上一帧更近的一个。**这不是改变姿态**，只是 $\text{统一 Quaternion 的符号分支，使数值序列更连续}$ ，避免在绘图或求差时把一次等价换号误判成一次剧烈运动。

# 17. 和题目二的完整对应

## 17.1 输入数据

IMU 直接给出的是 $\omega_x,\omega_y,\omega_z$ 与 $a_x,a_y,a_z$ ，其中 Gyroscope 给的是角速度，**不是姿态本身**：角速度描述姿态变化的快慢，必须积分之后才能得到姿态，这也正是 Day 2 要处理的传播问题。FAST-LIO 的 `pose_cov.csv` 给出 $[q_x,q_y,q_z,q_w]$ ，这是 FAST-LIO 已经估计得到的 Orientation，后续在 EKF 中用作 $\text{姿态 Observation}$ ，即滤波器的外部观测输入。

## 17.2 状态与误差

内部标称状态取 $q,\quad b_g$ ，其中 $q$ 是姿态 Quaternion， $b_g$ 是 Gyroscope Bias；把零偏放进状态是为了让滤波器能在线估计并扣除陀螺仪的常值偏差，而不是当作已知常量。误差状态取 $\delta\theta\in\mathbb R^3$ ：因此标称姿态是 4 维 Quaternion，姿态误差是 3 维 Rotation Vector —— 今天已为此建立前置几何直觉。

## 17.3 最终输出与职责划分

最终由 $q$ 得到 $q\rightarrow Roll,\ Pitch,\ Yaw$ ，然后绘制 Roll-Time、Pitch-Time、Yaw-Time。

内部使用 Quaternion 的原因：比 Rotation Matrix 更紧凑（ $4\text{ 参数 vs }9\text{ 参数}$ ）、没有 Euler Angle 的 Gimbal Lock、Rotation 复合自然（ $q_2\otimes q_1$ ）、适合连续姿态传播。最终输出 RPY 的原因：人类直观、便于判断 Roll / Pitch / Yaw 变化、适合画趋势曲线和检查实验结果。所以 $\displaystyle  \text{Quaternion 负责内部姿态表示与传播} $
而 $\displaystyle  \text{RPY 负责最终展示} $

# 18. 必须记住的易错点与认知修正

## 18.1 “正定矩阵” vs “正交矩阵”

最初理解“Rotation Matrix 有约束，因此 9 个参数只有 3 DOF”是对的，但把“正交”说成了“正定”。修正：Rotation Matrix 满足 $R^TR=I,\quad \det(R)=1$ 。

## 18.2 Rotation Vector 分量含义容易误解

误区： $[\phi_x,\phi_y,\phi_z]^T$ 是否分别表示 X/Y/Z 三个 Euler Angle？**不是。** 三个分量共同描述一根 Rotation Axis 与一个 Rotation Angle，即 $\phi=\theta n$ 。

## 18.3 Quaternion inverse 公式不能死记

$\displaystyle q^{-1} = \frac{q^*}{\|q\|^2}$ 成立的原因由下两式完成理解： $q q^*=\|q\|^2$ 以及 $q q^{-1}=1$ 。

## 18.4 $q^{-1}$ 与 $-q$ 的区别（最重要的概念边界之一）

$\displaystyle  q^{-1}\neq -q $ $q^{-1}$ 表示相反 Rotation； $-q$ 表示同一 Rotation 的另一个 Quaternion 表示。

## 18.5 “两种 Rotation 方式最终相同”的说法需要分层

从实际运动路径看， $90^\circ$ 与 $450^\circ$ 可以是不同 Motion；但从 Orientation / Rotation mapping 看 $R(90^\circ)=R(450^\circ)$ ，因此 $q$ 和 $-q$ 在姿态估计中必须视为同一个 Orientation。

## 18.6 Quaternion 与 Matrix 的类比（可继续复用）

$\displaystyle R_2R_1 \leftrightarrow q_2\otimes q_1$ $\displaystyle R^{-1} \leftrightarrow q^{-1}$ $\displaystyle Rp \leftrightarrow qpq^{-1}$ 以后学习 Quaternion Integration 时可以继续利用这条类比。

# 19. 关键公式速查

## Rotation Matrix

$\displaystyle R^TR=I, \qquad \det(R)=1, \qquad R^{-1}=R^T$ 坐标变换方向为 $\mathbf p_W=R_{WB}\mathbf p_B$ ，其中 $R_{WB}:B\rightarrow W$ ，反向用 $R_{BW}=R_{WB}^T$ 。

## Rotation Vector

- $\displaystyle \phi=\theta n, \qquad \theta=\|\phi\|, \qquad n=\frac{\phi}{\|\phi\|}$
## Axis-Angle → Quaternion

- $\displaystyle  q= \left[ n\sin\frac{\theta}{2}, \cos\frac{\theta}{2} \right] $
## Unit Quaternion / Conjugate / Inverse

单位四元数约束为 $\|q\|=1$ ；共轭为 $q^*=[-\mathbf v,w]$ ；逆为 $\displaystyle  q^{-1} = \frac{q^*}{\|q\|^2} $
当 $q$ 是 Unit Quaternion 时 $q^{-1}=q^*$ 。

## Double Cover

- $\displaystyle  q\equiv -q $
## Quaternion 旋转向量

$\displaystyle  p'=q p q^{-1} $ 其中向量按 $p=[p_x,p_y,p_z,0]$ 嵌入为纯四元数。

## Quaternion → Rotation Matrix

- $\displaystyle R= [1-2(y^2+z^2),\ 2(xy-zw),\ 2(xz+yw);\ 2(xy+zw),\ 1-2(x^2+z^2),\ 2(yz-xw);\ 2(xz-yw),\ 2(yz+xw),\ 1-2(x^2+y^2)]$
## ZYX Euler 与 RPY 提取

ZYX Euler 约定为 $\displaystyle  R=R_z(Yaw)R_y(Pitch)R_x(Roll) $
从 Rotation Matrix 提取的角度为 $\displaystyle Roll = \mathrm{atan2}(R_{32},R_{33})$ $\displaystyle Pitch = \arcsin(-R_{31})$ $\displaystyle Yaw = \mathrm{atan2}(R_{21},R_{11})$
直接由 Quaternion 提取的角度为 $\displaystyle Roll= \mathrm{atan2} \left( 2(wx+yz), 1-2(x^2+y^2) \right)$ $\displaystyle Pitch= \arcsin \left( 2(wy-zx) \right)$ $\displaystyle Yaw= \mathrm{atan2} \left( 2(wz+xy), 1-2(y^2+z^2) \right)$
## 符号连续性

- $\displaystyle d=q_{k-1}^Tq_k, \qquad q_k\leftarrow -q_k\quad(d<0)$
